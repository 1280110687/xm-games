# 主题四二级页面样式修复验证

## 修复范围

- 五个工具页：文本整理、JSON、Base64、二维码、文本加解密。补齐工作区、面板、输入框、模式选择、结果展示与响应式布局；JSON 保留缩进和横向滚动，文本结果保留换行并限制长内容溢出。
- 设置页：补齐图标/文案/控件布局，窄屏显示完整主题名称，预留底栏及安全区空间。
- 主题四居中游戏页头：窄屏使用 `auto minmax(0, 1fr) auto`，为右侧控制区保留实际宽度。
- 导航：房间、追番、设置互斥高亮，主页不渲染二级导航。
- 扫雷：仅状态卡调用处显式使用 `flex-row`，不修改通用 Card。
- 长停留检查额外发现的 PWA 提示：补齐固定定位、关闭按钮、说明、操作区与安装步骤布局，避免插入普通文档流。
- Service Worker 缓存版本从 v16 升到 v17，使发布后的安装包能够更新相关样式。

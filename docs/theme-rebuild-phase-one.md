# 主题重建：公共边界整理与旧版下线

2026-09-14。旧主题清理已完成；用户选中第三张「街机编辑部」样稿。首页和文本工具代表页之后，按用户本轮要求完成全部二级页面适配，移除主题一的设置中心导航入口。

## 当前可用范围

- 活跃主题：新版主题一、主题三、主题四。默认主题仍为主题三，保留用户已保存的选择。
- 新版主题一使用 `theme-arcade` 标识；旧 `theme-one`／`theme-two` 不会被重新激活。
- 新版主题一覆盖首页及全部 22 个游戏／工具入口。删除首屏脚本和 Provider 的路由回退逻辑，刷新或跳转二级页不再切到主题三。
- 主题一底栏只有首页／游戏库／工具；各页头部保留主题与语言切换。`/settings` 保留兼容旧链接，不再出现在主题一底栏。主题三、四导航未更改。
- 旧主题一、二的存储值在启动脚本中迁移到主题三；存储不可写时仍可正常显示回退主题。
- 主题一、二的六份 CSS、旧首页、旧底栏与舒尔特旧主题一布局已删除。旧版可从 Git 历史恢复，不另存废弃代码副本。
- 所有 22 个游戏／工具入口和 24 个页面路由仍然保留。
- 追番、跨设备拷贝、工具算法和游戏规则未调整。主题四的 3D 实现没有改动。

## 目录与职责

| 位置 | 职责 |
| --- | --- |
| `features/catalog/catalog.ts` | 共用分类、路由、标题和描述键，不保存主题配色或首页推荐权重 |
| `features/catalog/types.ts` | 主题三、四共用的目录契约 |
| `app/page.tsx` | 首页主题分发，不再包含数百行旧主题页面 |
| `lib/theme.ts` | 活跃主题、默认值、浏览器主题色、旧偏好迁移 |
| `features/themes/shared/` | Provider、切换入口和导航分发 |
| `features/themes/theme-arcade/` | 街机编辑部首页、文本工具、页头、专注训练视图、三项导航、路由分类和三语文案 |
| `features/themes/shared/focus-view.ts` | 专注训练视图插槽契约；主题之间不互相导入布局实现 |
| `styles/themes/theme-arcade/` | 按 shared／tools／games／anime 划分公共主题样式；classic-games／schulte-grid 仍仅在对应路由加载 |
| `features/tools/hooks/use-text-tool.ts` | 三个可用主题共用的文本输入、统计、处理与复制状态；算法仍归 `lib/offline-tools.ts` |
| `features/themes/theme-four/schulte-view.tsx` | 主题四的舒尔特页面排版；接受棋盘、操作等插槽，不拥有游戏规则 |
| `features/schulte-grid/components/schulte-grid-game.tsx` | 保留现有游戏状态、输入处理、计时、成绩及共享功能组件 |
| `styles/base/tokens.css` | 中性回退变量，不继承旧主题一的紫色外观 |
| `styles/themes/theme-three/`、`theme-four/` | 仍在使用的主题样式 |

主题四的 `schulte-two-*` 类名和变量已改为 `schulte-four-*`。对应 CSS 与修改前进行归一化比较，除命名变更外内容一致。

- SSR 根元素和 viewport theme-color 从 `DEFAULT_THEME`／`THEME_CONFIG` 读取，不再写死主题一。

- Service Worker 缓存版本本轮升为 v21，保持现有用户确认更新机制，不强制激活或清除业务存储；新版插画仍在完整离线清单中。

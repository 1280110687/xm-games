## 浏览器

- 本机 Chrome：开发入口从主站同源 URL 加载 `@vite/client`、原始 JSX 和 WebGL Canvas；进入技能房间显示嵌套竞技场，返回走廊后嵌套 iframe 数量恢复为 0。
- 390 × 844 视口：四套主题的首页、五子棋、2048 路径检查；四套 2048 截图检查通过，未见横向溢出。截图保留在本机忽略的 `output/playwright/`，不提交。
- 生产 Service Worker 完整包准备返回 `OFFLINE_PACKAGE_READY`，24 条路由、349 项缓存资源；测试时使用独立浏览器会话。
- 模拟离线时浏览器的 `navigator.onLine` 状态不稳定，因此最终关闭本机生产服务器，并用 curl 与不缓存的 API 请求确认服务器不可达。在此条件下重新进入主题四，打开技能房间，嵌套 Canvas 成功创建；再进入 JSON 工具、五子棋、2048、舒尔特方格，页面标题均正确。该结果证明缓存可在源服务不可达时提供本地资源，不等同于真实 iPhone 飞行模式验收。

## 限制与保留警告

- Vite 仍有大于 500 kB 的 3D chunk 提示，以及固定公开路径纸纹理的构建期解析提示；该纹理存在于素材源和发布目录，浏览器实际加载成功。本次不声称已改善重资源加载速度。
- OpenNext 构建存在生成依赖代码的重复 `options` 字段警告，但构建成功；没有修改第三方生成代码来消除警告。
- 离线导航时仍可见少量 Next.js RSC 预取请求失败；不能把“页面可进入”表述为“控制台零错误”。3D 场景还有浏览器图形和 iframe 属性警告。
- 没有在真实 iPhone 安装包、线上 Cloudflare Worker 或双手机联机场景上复测。原有安全区和联机协议不在本次功能变更范围。
- 上游素材许可限制不因本次搬迁而改变，详见两个应用的来源和许可证文件。

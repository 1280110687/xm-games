# Theme Four original assets

These two raster scenes were generated specifically for XM-Games. They do not
copy the reference project's personal characters, logos, stickers, textures,
copywriting, or other restricted portfolio artwork.

## `club-entrance.webp`

Final prompt:

> Create an ORIGINAL wide website hero background for XM-Games Theme 4, using
> the provided portfolio entrance screenshot only as high-level art-direction
> reference for a hand-drawn pencil-and-paper world. Do not reproduce any
> existing character, logo, sign text, stickers, composition-specific
> decorations, or personal imagery from the reference. Make a responsive 16:10
> neighborhood game-club facade on warm off-white watercolor paper, with large
> centered double wooden doors, a completely blank hanging sign, a tree and
> bench with board-game pieces on the left, and an arched window, planters,
> small arcade cabinet, and geometric toys on the right. Use graphite outlines,
> cross-hatching, erased construction lines, subtle paper grain, and restrained
> watercolor only on the door and a few game objects. Keep the central area
> clear for HTML overlays. Include no text, logos, watermarks, UI, neon, glossy
> 3D, photorealism, programming icons, or copyrighted characters.

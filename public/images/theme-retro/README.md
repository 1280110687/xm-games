# Retro handheld theme assets

Generated with the built-in ImageGen tool using the user's selected retro handheld concept. Resized and encoded to WebP with Sharp; no third-party game artwork is bundled.

| File | Use |
| --- | --- |
| lcd-frame.webp | Empty LCD screen and bezel, with live UI text overlaid |
| cartridge.webp | Blank cartridge casing, with live labels and game artwork |
| tiles-lcd.webp | Monochrome 2048 preview |
| gomoku-lcd.webp | Monochrome Gomoku preview |
| snake-lcd.webp | Monochrome Snake preview |
| shell-texture.webp | Subtle repeating shell material |
| vent-grille.webp | Decorative speaker vents |

Images are presentation-only. The game catalog, navigation, controls and actual game boards remain functional application components.

The pixel typeface is [Silkscreen by Jason Kottke](https://github.com/googlefonts/silkscreen), downloaded from the Google Fonts repository. Its SIL Open Font License is included at `public/fonts/silkscreen/OFL.txt`. Fonts are served locally and included in the offline package.
